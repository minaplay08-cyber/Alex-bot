# 🤖 Алекс — Telegram AI Бот

Живой собеседник с памятью. Запоминает вас, ваши темы, факты. Может быть обычным парнем или "тёмным героем".

## 🚀 Быстрый старт

```bash
pip install -r requirements.txt
cp .env.example .env
python main.py
```

**Groq API**: [console.groq.com](https://console.groq.com) → API Keys
**Telegram Bot**: **@BotFather** → `/newbot`

## 🧠 Память бота

Бот запоминает:
- **История** — последние 60 сообщений
- **Темы** — о чём вы говорили (работа, учёба, фильмы...)
- **Контекст** — помнит о чём был предыдущий разговор

### Команды памяти
| Команда | Что делает |
|---------|------------|
| `/memory` | Показать что бот помнит |
| `/forget` | Стереть память (начать с чистого листа) |
| `/reset` | Очистить историю чата (память сохраняется) |

## 🎮 Команды

### Профиль
| Команда | Что делает |
|---------|------------|
| `/profile` | Посмотреть профиль |
| `/setname` Имя | Указать имя |
| `/setgender` | Выбрать пол |
| `/setappearance` | Описать внешность |
| `/setinterests` | Рассказать об интересах |

### Режимы
| Команда | Что делает |
|---------|------------|
| `/dark` | Режим "тёмный герой" 🌙 |
| `/normal` | Обычный стиль |
| `/remind` | Напоминания (8:00 + 21:00) |

## 💾 Сохранение

Все данные в `user_data.json`:
- Профиль
- Настройки
- История (60 сообщений)
- Память (темы, факты)

## 📝 Пример

```
Ты: Я вчера смотрел крутой фильм
Бот: Какой? Поделись!

Ты: "Довод" Нолана
Бот: О, класс! Ты любишь такое запутанное кино?

...через час...

Бот: Кстати, ты так и не рассказал, какой фильм Нолана смотрел. Понравился?
```
